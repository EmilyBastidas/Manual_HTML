# 1. ¿Qué es HTML?

HTML significa:

**HyperText Markup Language**

En español:

**Lenguaje de Marcado de Hipertexto.**

HTML es el lenguaje utilizado para crear la **estructura y el contenido de una página web**.

HTML permite indicar al navegador qué elementos existen en una página:

- Títulos
- Párrafos
- Imágenes
- Enlaces
- Listas
- Tablas
- Formularios
- Videos
- Secciones
- Navegación
- Etc.

HTML **no es un lenguaje de programación**.

Es un lenguaje de marcado.

---

## ¿Qué significa "marcado"?

HTML utiliza etiquetas para marcar o describir qué representa cada parte del contenido.

Por ejemplo:

```html
<h1>Mi página web</h1>
```
