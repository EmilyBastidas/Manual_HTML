# 1. ¿Qué es HTML?

HTML significa **HyperText Markup Language** (Lenguaje de Marcado de Hipertexto).

Es el lenguaje utilizado para **crear y estructurar el contenido de una página web**.

HTML permite indicar al navegador qué elementos existen en una página, por ejemplo:

- Títulos
- Párrafos
- Imágenes
- Enlaces
- Listas
- Tablas
- Formularios
- Botones
- Secciones

HTML **no es un lenguaje de programación**, sino un **lenguaje de marcado**.

Su función principal es definir la **estructura y el significado del contenido** de una página web.

### ¿Cómo funciona?

HTML utiliza **etiquetas (tags)** para indicar al navegador qué representa cada elemento.

Por ejemplo:

```html
<h1>Mi primera página web</h1>
<p>Este es un párrafo.</p>
```
